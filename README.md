## Запуск

Статичний HTML/CSS/JavaScript. Збірка та залежності не потрібні.
Публікація: GitHub Pages, гілка main, коренева папка.

Для локального перегляду:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

## Функції

Каталог Good Hair та 12 засобів System 4 із фільтрами категорій.
Форми перевіряють ім’я, український телефон і згоду, після чого готують лист.
Відвідувач сам надсилає його зі своєї пошти. Автоматичного надсилання немає.
Ціни, наявність, спосіб оплати й доставку узгоджують перед підтвердженням.

Описи й фотографії System 4 взято з наданого каталогу виробника.
Торгові марки й права на продукцію належать відповідним власникам.
